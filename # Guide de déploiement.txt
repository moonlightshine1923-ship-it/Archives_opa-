# Guide de déploiement — Archives OPA

**Cible :** PC / serveur **Windows Server** (2016, 2019, 2022 ou 2025)  
**Application :** Node.js + Express + MySQL, fichiers stockés sur le disque  
**Accès :** réseau local du bureau uniquement (`http://IP-DU-SERVEUR:3000`)

---

## 0. Ce que tu auras à la fin

- L’appli tourne sur le serveur Windows
- Elle **redémarre toute seule** le matin quand tu allumes le PC
- Les employés ouvrent l’appli par une **icône sur le Bureau**
- Les fichiers sensibles restent **sur le disque du serveur** (pas chez un hébergeur)
- Le serveur peut **s’éteindre la nuit** sans casser l’installation

---

## 1. Matériel et préparation

### Machine

| Élément | Minimum | Conseillé |
|---|---|---|
| RAM | 8 Go | 16 Go |
| Système | SSD 128–256 Go | SSD 256 Go+ |
| Fichiers d’archives | HDD/SSD **1 To** | 2–4 To sur un 2ᵉ disque (`D:`) |
| Réseau | Câble Ethernet | Câble Ethernet (pas le Wi‑Fi) |

Le PC doit rester **allumé pendant les heures de bureau**. La nuit, tu peux l’éteindre.

### Compte Windows

Installe et administre l’appli avec un compte **Administrateur**.  
Ensuite, l’appli tournera en service : personne n’a besoin d’être connecté à l’écran.

### IP fixe (à faire tôt)

1. Sur le serveur : `Windows + R` → `cmd` → `ipconfig`
2. Note :
   - **Adresse IPv4** (ex. `192.168.1.50`)
   - **Masque** (souvent `255.255.255.0`)
   - **Passerelle** (souvent `192.168.1.1`)
3. Paramètres → Réseau → Ethernet → Modifier les options de l’adaptateur  
   Clic droit sur la carte → Propriétés → **Protocole Internet version 4 (TCP/IPv4)**  
   → Utiliser l’adresse IP suivante → remplis les 3 valeurs  
   DNS : `192.168.1.1` et `8.8.8.8`

Dans tout ce guide, on utilise **`192.168.1.50`**. Remplace-la par **ton** IP.

## 2. Installer les logiciels

### 2.1 Node.js

1. Sur le serveur, ouvre un navigateur : https://nodejs.org/
2. Télécharge **LTS** (version 20 ou 22)
3. Installe avec les options par défaut  
   Coche **« Automatically install the necessary tools »** si proposé
4. Ferme toutes les fenêtres cmd, rouvre une **Invite de commandes** :

```bat
node -v
npm -v
```

Tu dois voir des numéros de version. Sinon, redémarre le serveur et réessaie.

### 2.2 MySQL

1. https://dev.mysql.com/downloads/installer/  
   Choisis **Windows (x86, 64-bit), MSI** — « mysql-installer-community »
2. Type d’installation : **Server only** ou **Custom** (MySQL Server suffit)
3. Mot de passe **root** : choisis un mot de passe **fort**, note-le
4. Port : **3306** (défaut)
5. Windows Service : **MySQL80** (ou similaire) → **Start at System Startup** = oui

Vérifie :

```bat
sc query MySQL80
```

(`STATE` doit être `RUNNING`. Le nom exact peut être `MySQL57`, `MySQL`, etc. : `services.msc` pour le voir.)

### 2.3 Outil optionnel

[HeidiSQL](https://www.heidisql.com/) — pour voir les tables sans ligne de commande.


Ouvre **Invite de commandes** :

```bat
cd C:\archives-opa

```

Attends la fin sans erreur rouge.

## 4. Fichier de configuration `.env`

Dans `C:\archives-opa`, crée un fichier nommé **`.env`** (avec le point).

Astuce : Bloc-notes → Enregistrer sous → Nom : `.env` → Type : **Tous les fichiers**.

Contenu (adapte les mots de passe) :

```env
PORT=3000

DB_HOST=localhost
DB_PORT=3306
DB_USER=archives_user
DB_PASSWORD=ChangeMoi_MotDePasseFort_2026
DB_NAME=archives_db

JWT_SECRET=change-cette-phrase-secrete-tres-longue-et-aleatoire
MAX_FILE_SIZE=104857600
ALLOWED_EXTENSIONS=pdf,doc,docx,xls,xlsx,ppt,pptx,jpg,jpeg,png,zip
```

- `JWT_SECRET` : une longue phrase unique. Ne la partage pas.
- `MAX_FILE_SIZE=104857600` = **100 Mo** par fichier. Augmente si besoin (`209715200` = 200 Mo).

## 5. Créer la base de données

### 5.1 Ouvrir MySQL

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p
```

(Le chemin peut être `8.4` ou `8.0` : regarde dans `C:\Program Files\MySQL\`.)

Tape le mot de passe **root**.

### 5.2 Commandes SQL

```sql
CREATE DATABASE archives_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER 'archives_user'@'localhost' IDENTIFIED BY 'ChangeMoi_MotDePasseFort_2026';

GRANT ALL PRIVILEGES ON archives_db.* TO 'archives_user'@'localhost';
FLUSH PRIVILEGES;

EXIT;
```

Le mot de passe doit être **identique** à `DB_PASSWORD` du `.env`.

### 5.3 Initialiser les tables

```bat
cd C:\archives-opa
npm run init-db
```

Si ça échoue, importe à la main :

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u archives_user -p archives_db < C:\archives-opa\sql\schema.sql
```

## 6. Premier test (avant le service)

```bat
cd C:\archives-opa
npm start
```

Tu dois voir un message du type « Serveur démarré » / port **3000**.

Sur **le serveur** : ouvre Edge → http://localhost:3000

Connexion par défaut (à changer tout de suite) :

| Email | Mot de passe |
|---|---|
| `superadmin@archives.dz` | `admin123` |

Si la page s’affiche : **Ctrl+C** dans la fenêtre pour arrêter. On va la lancer proprement ensuite.

## 7. Gros disque pour les fichiers (stockage)

Les documents uploadés vont dans :

`C:\archives-opa\public\uploads\`

Pour les mettre sur un gros disque `D:` :

```bat
mkdir D:\archives-fichiers
mkdir D:\sauvegardes
```

Si `C:\archives-opa\public\uploads` existe déjà et n’est pas vide, déplace son contenu vers `D:\archives-fichiers` d’abord.

Puis (Invite de commandes **Administrateur**) :

```bat
rmdir /S /Q C:\archives-opa\public\uploads
mklink /J C:\archives-opa\public\uploads D:\archives-fichiers
```

L’appli écrit dans `public\uploads`, les fichiers sont réellement sur `D:\`.

---

## 8. Lancer l’appli au démarrage (PM2)

Le serveur s’éteint la nuit : il faut que Node reparte **sans ouvrir une fenêtre**.

### 8.1 Installer PM2 (Invite de commandes **Administrateur**)

```bat
npm install -g pm2
npm install -g pm2-windows-startup
```

### 8.2 Enregistrer l’application

```bat
cd C:\archives-opa
pm2 start server\app.js --name archives
pm2 save
pm2-startup install
pm2 save
```

### 8.3 Commandes utiles

```bat
pm2 status
pm2 logs archives
pm2 restart archives
pm2 stop archives
```

Redémarre Windows une fois pour vérifier : après 1–2 minutes, http://localhost:3000 doit répondre **sans rien lancer à la main**.

MySQL est déjà un service Windows : il démarre tout seul. Vérifie dans `services.msc` que le service MySQL est en **Automatique**.

## 9. Pare-feu Windows Server

Sans ça, les autres PC ne pourront pas se connecter.

1. `wf.msc` (Pare-feu Windows Defender avec fonctions avancées)
2. **Règles de trafic entrant** → Nouvelle règle
3. **Port** → Suivant
4. TCP → Ports locaux spécifiques : **3000**
5. Autoriser la connexion
6. Profils : **Domaine** + **Privé** (décoche Public si le serveur n’est pas exposé)
7. Nom : `Archives OPA`

Test depuis un **autre PC** du bureau :

```
http://192.168.1.50:3000
```

## 10. Icône sur le Bureau des employés

Rien à installer sur leur PC. C’est un raccourci web.

### Créer le raccourci

1. Sur un PC employé (ou sur le serveur) : Bureau → clic droit → **Nouveau** → **Raccourci**
2. Emplacement :

```
http://192.168.1.50:3000
```

3. Nom : **Archives OPA**

Fichier équivalent (Bloc-notes → enregistrer `Archives OPA.url` sur le Bureau) :

```ini
[InternetShortcut]
URL=http://192.168.1.50:3000
```

Pour l’icône de **l’onglet** du navigateur : place `Archives.png` dans `C:\archives-opa\public\Archives.png` (déjà prévu dans `index.html`).

### Déployer sur tous les postes

- Copie `Archives OPA.url` via clé USB / dossier partagé  
- Ou, si les PC sont dans un **domaine Active Directory** : GPO → Préférences utilisateur → Raccourcis → Bureau → URL

Les employés double-cliquent → le navigateur s’ouvre → ils se connectent avec **leur** compte.

## 11. Allumage le matin, extinction le soir

| Moment | Action |
|---|---|
| Soir | Arrêter Windows normalement (pas couper le courant) |
| Matin | Allumer le serveur (bouton ou réveil BIOS) |
| + 1 à 2 min | MySQL + PM2 sont prêts |
| Employés | Double-clic sur l’icône |

Si quelqu’un ouvre trop tôt : page blanche / erreur → attendre et actualiser (`F5`).

### Allumage automatique (optionnel)

Redémarre → entre dans le **BIOS/UEFI** (souvent F2, Del, F10)  
Cherche : *Resume by RTC*, *Power-on by Alarm*, *RTC Alarm*  
Active et mets l’heure (ex. 07:30).

Ça dépend de la carte mère ; ce n’est pas obligatoire.

## 12. Sécurité (documents sensibles)

1. **Pas d’ouverture du port 3000 sur Internet** (pas de redirection sur la box).
2. Accès hors bureau = **VPN** (Tailscale ou VPN Windows), jamais le port nu.
3. Change tout de suite `admin123`.
4. Un compte par personne, pas un mot de passe partagé.
5. Active **BitLocker** sur `D:` (chiffrement si le disque est volé).
6. Windows Update : installe les mises à jour hors heures de bureau.
7. Compte Windows du quotidien : pas besoin d’être admin pour que l’appli tourne (PM2 en service).

## 13. Sauvegardes (obligatoire)

Deux choses à sauver **chaque jour** :

1. La **base** MySQL  
2. Le dossier **fichiers** `D:\archives-fichiers`

Crée `C:\archives-opa\sauvegarde.bat` :

```bat
@echo off
set JOUR=%date:~6,4%-%date:~3,2%-%date:~0,2%
set DEST=D:\sauvegardes\%JOUR%
mkdir "%DEST%"

"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u archives_user -pChangeMoi_MotDePasseFort_2026 archives_db > "%DEST%\archives_db.sql"

robocopy D:\archives-fichiers "%DEST%\fichiers" /MIR /R:1 /W:1

echo Sauvegarde terminee %date% %time% >> D:\sauvegardes\log.txt
```

Adapte le chemin `mysqldump.exe` et le mot de passe.

**Planifier** : `taskschd.msc` → Créer une tâche de base  
- Nom : `Sauvegarde Archives`  
- Déclencheur : tous les jours à 18:00 (avant l’extinction)  
- Action : démarrer `C:\archives-opa\sauvegarde.bat`  
- Exécuter même si l’utilisateur n’est pas connecté

Copie aussi de temps en temps `D:\sauvegardes` vers un **disque USB** que tu débranches (incendie / ransomware).

## 15. Mise à jour de l’appli (quand tu reçois de nouveaux fichiers)

1. Préviens les utilisateurs
2. `pm2 stop archives`
3. Remplace uniquement les fichiers demandés (`public\js\app.js`, `server\routes\...`, etc.)  
   **Ne touche pas** à `.env` ni à `public\uploads` / `D:\archives-fichiers`
4. `pm2 start archives`  
   ou `pm2 restart archives`
5. Sur un PC : **Ctrl + F5**

## 16. Problèmes fréquents

| Symptôme | Cause probable | Que faire |
|---|---|---|
| `localhost:3000` ne répond pas | PM2 / Node pas lancé | `pm2 status` puis `pm2 restart archives` |
| Ça marche sur le serveur, pas sur les autres PC | Pare-feu ou mauvaise IP | Règle TCP 3000 + vérifier `ipconfig` |
| `Erreur serveur` / 500 | MySQL arrêté ou mauvais `.env` | `services.msc` → MySQL Démarrer ; relire `.env` |
| Page blanche après une mise à jour | Ancien JavaScript en cache | Ctrl + F5, ou navigation privée |
| Upload échoue | Disque plein ou droits | Espace libre sur `D:` ; jonction `uploads` |
| Au matin ça ne marche pas | PM2 pas en service | Refaire `pm2-startup install` **en admin** |
| Mot de passe oublié | — | Dans HeidiSQL, table `users` : il faut recréer un hash bcrypt (plus simple : un 2ᵉ admin te réinitialise le mot de passe dans l’appli) |

Logs :

```bat
pm2 logs archives
```
